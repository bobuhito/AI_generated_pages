Exact directional sine-wave fit through five points

A rotated sine wave has five unknowns: amplitude A, wavelength λ, phase φ, offset C and propagation angle θ. Five points therefore give a determined system with isolated exact solutions. The smoothest solution is the one with the longest wavelength.

u = x·cosθ + y·sinθ    v = −x·sinθ + y·cosθ    v = A·sin(2π·u/λ + φ) + C

    How the solver works

    For a fixed wavelength and angle the five equations are linear in (A·cosφ, A·sinφ, C), so an exact fit exists only where the 4×4 determinants of that linear system all vanish. That turns the problem into locating the zeros of a function of just two variables, (λ, θ). The page covers the landscape with rectangles; for each rectangle interval arithmetic gives guaranteed bounds on the determinants, and a rectangle whose bounds exclude zero is proven empty (and blacked out). A second 2-D Newton-type test (interval Krawczyk) excludes thin “valley” cells that the plain bounds cannot. Surviving rectangles seed an ordinary 2-D Newton iteration that polishes a zero to machine precision. A further interval-Newton test then proves that a rectangle around that zero contains exactly one exact fit, so the rectangle never needs refining again. Refine repeats halving and testing on whatever is left, for about a tenth of a second per press. A solution marked “proven isolated” is backed by that guarantee; “not proven” means the solver found an exact fit but could not separate it from a possible close neighbour. Nothing is ever claimed empty without proof. The search starts at λ ≈ 0.31 × the span of the points and widens to shorter wavelengths only if nothing is found; type a shorter (or longer) wavelength in the Solver card to choose the range yourself. Interval bounds emulate outward rounding with small safety margins rather than true directed rounding.
